결론

현재 PoC는 무료로 시작할 수 있다. Azure Speech Translation F0는 월 5시간을 무료로 제공한다. 동시 실시간 요청은 1개이므로 두 참가자가 번갈아 말하는 Push-to-Talk 방식으로 검증한다.

무료 PoC 운영 방식

  1. 두 사용자는 동일한 웹 회의방에 접속한다.
  2. 한 사용자가 말하기 버튼을 누르면 다른 사용자의 버튼을 잠근다.
  3. 누른 사용자의 음성만 Azure로 전송한다.
  4. 상대 사용자는 원문과 번역 자막을 실시간으로 받는다.
  5. 말하기가 끝나면 Azure 세션을 해제하고 다음 참가자가 말한다.
무료 5시간은 유료 사용량에서 자동으로 공제되는 할인으로 가정하면 안 된다. F0는 별도 무료 리소스와 사용 한도다. 한도를 초과하거나 동시 요청이 필요하면 유료 계층 전환 여부를 확인한다.

향후 4개 언어 확장 시

한국어·영어 PoC는 한 개 대상 언어만 번역하므로 Speech Translation 기본 요금 범위에 들어간다. 향후 한 발화를 나머지 세 언어로 동시에 번역하면 세 번째 대상 언어부터 Translator 문자 요금이 추가될 수 있다.

  • 한 개 입력 음성과 최대 두 개 텍스트 대상 언어: Speech Translation 요금 범위
  • 세 번째 이상 대상 언어: Translator Text 가격표 추가 확인
  • 참가자별 음성을 계속 전송하면 참가자 수만큼 audio hours가 증가
  • VAD와 Push-to-Talk으로 실제 발화 구간만 전송하면 불필요한 비용 감소

Azure 외 무료 번역 모델

가장 현실적인 무료 조합은 Whisper + M2M100 418M이다. Whisper가 회의 음성을 문자로 바꾸고, M2M100이 그 문장을 한국어·영어·중국어·베트남어 사이에서 번역한다. 모델과 코드는 무료지만 회사 PC나 자체 서버의 장비·전기·운영 비용은 발생한다.

권장 PoC 전환 구조

브라우저 마이크 → 음성인식 Provider → 번역 Provider → WebSocket 자막

  1. 1차 PoC는 기존 결정대로 Azure F0를 사용해 전체 회의 흐름을 빠르게 검증한다.
  2. 프로그램 내부에서 Azure와 로컬 모델을 동일한 Provider 인터페이스로 분리한다.
  3. 2차 검증에서 Whisper + M2M100을 추가해 속도·정확도·장비 사용량을 같은 문장으로 비교한다.
  4. 정식 전환 때 보안, 품질, 동시 사용자 수와 총운영비를 기준으로 Azure 또는 자체 운영을 선택한다.

이 구조라면 현재 Azure로 시작해도 특정 서비스에 강하게 종속되지 않으며, 중국어와 베트남어도 동일한 언어 설정과 Provider 구조 안에서 단계적으로 추가할 수 있다.
